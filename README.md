## 🚀 CocoBase — Backend as a Service

<a href="https://cocobase.cc">
  <img align="right" width="200" src="https://img.shields.io/badge/Try_CocoBase-6366F1?style=for-the-badge&logo=rocket&logoColor=white" />
</a>

The platform I'm building: instant backend for any app. Schemaless collections, JWT auth, file storage, Python cloud functions, real-time WebSockets, and an MCP server so AI tools like Claude can manage your project directly.

| Repo | Stack | |
